# Demo specification

## Primary visitor task

Understand what A&M hauls, confirm that Columbia is the service center, and start a phone or text conversation.

## Content sequence

1. Teal dispatch hero with owner logo and custom truck/trailer illustration
2. Service manifest
3. Interactive item selector that prepares a text message
4. Concentric Columbia service-area graphic
5. Owner-published duplex cleanout field note
6. Direct call, text, and Facebook paths

## Exact inspiration

https://dribbble.com/shots/26307574-Junk-Removal-Website-Design

## Technical

- React and Tailwind CSS
- Reduced-motion fallback
- Keyboard-operable load buttons and semantic links
- Phone-first responsive layout
- Static concept; no data is submitted or stored
